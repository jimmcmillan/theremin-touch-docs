# theremin-touch-docs

Support site for Theremin Touch (App Store id 1168287678). Plain HTML, no build step.

## Publish

1. Push `index.html`, `privacy.html`, `style.css` and the `images/` folder to the `main` branch root.
2. Repo › Settings › Pages › Source: "Deploy from a branch", Branch: `main`, folder: `/ (root)`. Save.
3. Site appears at `https://<user>.github.io/theremin-touch-docs/` within a minute or two.

## App Store Connect

- Support URL: `https://<user>.github.io/theremin-touch-docs/`
- Privacy Policy URL: `https://<user>.github.io/theremin-touch-docs/privacy.html`
- Marketing URL: optional; leave blank or use the support URL.
